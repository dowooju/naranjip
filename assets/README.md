# Furniture atlas

- 파일: `furniture-atlas.png` (1448×1086 PNG, 실제 alpha 투명도)
- 생성 방식: 내장 image_gen 도구. 레퍼런스의 2000년대 미니홈피/꾸미기 게임 분위기를 참고한 신규 이미지입니다.
- 4열 × 3행. 행 순서: 의자/책상/소파/식탁, 냉장고/문/액자/쪽지, 작은 화분/큰 화분/러그/빈 칸.
- 원본 alpha를 보존합니다. atlas를 잘라 저장하지 않고 Canvas가 소스 영역만 표시합니다.
- 사용 경로와 S3 교체 계약: `docs/ROOM-EDITOR.md`.

## 생성 프롬프트

Create a production PNG sprite atlas for a nostalgic early-2000s Korean mini-homepage isometric room decoration game. ONE SINGLE image, transparent background with true alpha. Exactly 4 equal columns and 3 equal rows, all cells equal square size. Each object isolated strictly inside its own cell with at least 12% transparent padding; no objects crossing cells, no grid lines, NO text or labels. Consistent 2:1 isometric perspective viewed from above, visible top and front/right side, objects sit centered near the lower center of each cell. Crisp detailed pixel-art inspired digital game illustration, candy pink and lavender, ivory wood, little gold edges, hearts and floral motifs, cute slightly kitschy 2000s dollhouse game, NOT flat vector or photorealistic. Row1 col1: ornate pink upholstered single chair. Row1 col2: ivory and pink writing desk with two drawers, empty tabletop. Row1 col3: plush hot-pink two-seat sofa with heart pillows. Row1 col4: pink ivory rectangular dining table, empty top, no chairs. Row2 col1: tall pastel pink two-door refrigerator with no notes or decorations. Row2 col2: ornate pink closed door in ivory frame, no wall, tall upright isometric wall-mounted object. Row2 col3: small gold ornate tabletop photo frame holding a generic flower picture, no text. Row2 col4: small yellow sticky note with pink heart-shaped pin, blank no writing. Row3 col1: small leafy green plant in a round pink pot. Row3 col2: tall leafy ficus tree in a lavender pot. Row3 col3: flat rectangular pink rug with ivory lace border and a heart motif, clearly lying flat in the isometric floor plane. Row3 col4: leave COMPLETELY EMPTY and transparent. Do not add any room background, floor, shadows beyond each isolated object's own subtle shadow, characters, logos, extra objects. Output a square canvas ideally 1536x1536, preserving exact evenly spaced 4x3 cell layout (cells rectangular if necessary). This atlas will be sliced mathematically at exactly quarters of width and thirds of height, so all 11 objects must remain well inside their correct cell.
