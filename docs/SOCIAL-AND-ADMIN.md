# 좋아요·코멘트·이번 주 콘셉트

01·02·03의 일반/콘셉트 하트와 방명록 규칙을 따릅니다. 이번 요청에 따라 기존 CLI 전용 콘셉트 운영 대신 관리자 전용 웹 화면을 제공합니다. “컨셉 코멘트”는 관리자가 작성하는 꾸미기 안내문입니다.

## sudo1234 관리자 준비

1. 사이트에서 sudo1234로 회원가입합니다. 비밀번호는 가입 화면에서 직접 정하세요.
2. Rancher Desktop을 켜고 프로젝트 폴더에서 PowerShell을 실행합니다.

~~~powershell
Set-Location -LiteralPath 'C:\Users\LG PC\Desktop\github\naranjip'
.\scripts\set-admin.ps1 -LoginId sudo1234
~~~

이미 있는 계정에만 권한을 줍니다. 계정을 생성하거나 비밀번호를 바꾸지 않습니다. PC의 Kubernetes 운영 권한이 있어야 실행할 수 있습니다. 가입 시 누구나 관리자 권한을 요청할 수 있는 웹 API는 없습니다.

## 매주 콘셉트 등록

1. sudo1234로 로그인하고 홈 오른쪽의 **이번 주 콘셉트 관리**를 누릅니다. 직접 주소는 /#admin입니다.
2. 제목(최대 80자)을 적습니다. 예: “비 오는 날의 집”.
3. 컨셉 코멘트(최대 1,000자)를 적습니다. 예: “빗소리를 들으며 쉬고 싶은 방을 꾸며 주세요. 차분한 색과 포근한 소품으로 표현해 보세요.”
4. **이번 주 콘셉트 공개하기**를 누르고 확인합니다.
5. 홈과 집 보기의 제목·안내문, 이번 주 콘셉트 순위를 확인합니다. 이미 열려 있는 화면은 새로고침하세요.

등록 즉시 활성화되며 날짜에 맞춰 자동 변경하지 않습니다. 매주 관리자가 등록합니다. 새 등록은 새 콘셉트 ID이므로 콘셉트 좋아요가 0부터 집계됩니다. 이전 투표와 주제는 DB 기록으로 남고 일반 좋아요·코멘트는 유지됩니다. 단순 문구 수정 기능은 별도로 제공하지 않으니 공개 전 내용을 확인하세요.

권한 회수:

~~~powershell
.\scripts\set-admin.ps1 -LoginId sudo1234 -Revoke
~~~

권한은 요청마다 DB에서 확인하므로 이미 로그인한 계정도 회수 즉시 관리 API를 사용할 수 없습니다.

## 사용자 기능

- 홈 순위 카드/이웃집 구경하기로 집을 방문합니다. 비로그인도 집과 코멘트를 읽을 수 있습니다.
- 로그인한 계정은 집마다 일반 좋아요 하나, 콘셉트별 좋아요 하나를 줄 수 있습니다. 다시 누르면 해당 좋아요만 취소합니다.
- 커플을 포함한 집 멤버는 자기 집에 좋아요를 줄 수 없습니다.
- 코멘트는 1~200자, 최신순, 20개씩 표시합니다. 작성자 또는 해당 집 멤버가 삭제할 수 있습니다. 작성자 이름으로 현재 집을 방문할 수 있습니다.
- 좋아요/댓글에서 로그인하면 원래 방문하던 집으로 돌아옵니다. 로그인만으로 반응을 자동 등록하지 않습니다.
- 꾸민 집만 순위/랜덤 후보가 됩니다. 동점은 공동 순위, 최대 50집, 0표는 순위 숫자를 표시하지 않습니다.
- 그림·액자·쪽지 내용 편집은 이번 변경에 포함하지 않았습니다. 현재 공개 방문에는 가구 종류·위치 등 배치만 제공됩니다.

## DB와 API

V4: accounts.is_admin(기본 false), themes, active_theme(싱글턴), general_likes, theme_likes, guestbook.

좋아요는 복합 PK로 중복을 막고 PUT/DELETE는 재시도해도 같은 결과입니다. 콘셉트 변경/투표는 같은 active_theme 행을 잠그며, 화면의 themeId가 오래되면 409로 거절합니다. 집 삭제 시 해당 집 반응을 함께 지우지만 다른 집에 남긴 반응은 유지합니다.

GET /api/theme, /api/rankings, /api/visits/{id}, /api/houses/random, /api/houses/{id}/social, /api/houses/{id}/guestbook.
PUT·DELETE /api/houses/{id}/likes/general 또는 theme, POST /api/houses/{id}/guestbook, DELETE /api/guestbook/{id}.
관리자 전용 GET·POST /api/admin/themes. 모든 변경 요청은 CSRF 검증을 거칩니다.
