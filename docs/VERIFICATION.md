# 첫 버전 검증 기록

> **k8s 시절 기록**: 아래는 Rancher Desktop Kubernetes로 실행하던 때의 검증 기록입니다. 지금은 Docker Compose로 실행합니다. Pod·PVC·port-forward 같은 표현은 당시 환경을 뜻합니다.

## 꾸미기 확장 (2026-11-09)

- JUnit 10개 + Node 배치 미리보기 테스트 3개 통과.
- Docker Linux 이미지 빌드 및 테스트 성공.
- 독립된 headless Chrome에서 실제 포인터 이벤트로 검증: 전체 화면 전환, 가구 11종 이미지 로딩, 드래그 추가, 겹침 취소, 러그 레이어, 회전, 문 벽 배치, 액자/쪽지 부착, 기존 가구 이동/삭제, 구경 화면 복귀, 새로고침 유지.
- 1440×1000 / 390×844 스크린샷 확인. 모바일 가로 넘침을 수정하고 완료 버튼과 캔버스가 화면 안에 있는지 확인.
- 부모 삭제 시 부착물 삭제 확인, 부착 개수 제한, 타인 집 접근 거절, stale revision 거절, 두 동시 요청 중 한 건 확정은 서버 테스트에서 검증.
- 실제 네트워크 단절 타이밍별 E2E와 WebSocket 공동 편집은 검증 범위에 포함하지 않음.
- 아래 기록은 가구 구현 전 첫 버전의 기록입니다.

## 검증 제한

- 대화의 브라우저 도구가 `[3학년]` 작업 경로 처리 오류로 시작하지 못해 브라우저 클릭 기반 E2E 검증은 수행하지 못했습니다.
- 두 번째 기기의 LAN 접속은 아직 확인하지 않았습니다.
- 로컬 CD runner는 등록하지 않았습니다. `ENABLE_LOCAL_CD`는 사용자가 runner를 연결한 뒤 켭니다.
- GitHub Actions 원격 실행 결과는 Actions 페이지에서 확인합니다. 워크플로 제공과 원격 실행 성공은 구분합니다.

## 직접 화면 확인 순서

1. 홈에서 왼쪽 두 탭을 전환하고 준비 중 상태를 확인합니다.
2. 아무 아이디로 로그인하고 빈 집이 보이는지 확인합니다.
3. 수정하기 → 꾸미기 완료 → 마을로 돌아가기 → 우리집 가기를 확인합니다.
4. 좋아요/콘셉트 좋아요/코멘트 버튼이 저장 없이 준비 중 안내를 띄우는지 확인합니다.
5. 새로고침 후 로그인 유지, 로그아웃 후 홈 복귀를 확인합니다.
6. 회원가입 화면에서도 임의 아이디로 시작되는지 확인합니다.
7. 모바일 폭에서 카드가 세로로 배치되고 가로 넘침이 없는지 확인합니다.
