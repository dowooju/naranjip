# 검증 기록

지금의 검증은 GitHub Actions가 매번 자동으로 합니다([CI 안내](CI-CD.md)). 아래는 그 전에 손으로 확인한 기록입니다.

> **k8s 시절 기록**: 2026-11-09 ~ 11-11에는 Rancher Desktop Kubernetes로 실행했습니다. Pod·PVC·port-forward는 당시 환경을 뜻합니다. 당시 쓰던 Chrome 디버그용 검사 스크립트는 지금은 저장소에서 삭제했습니다.

## 첫 버전과 꾸미기 (2026-11-09)

- Java 21 + Maven `verify` 성공, Dockerfile 다단계 빌드 성공, Kubernetes 배포·readiness UP 확인.
- headless Chrome에서 전체 화면 편집, 가구 11종 드래그·회전·삭제, 문 벽 배치, 액자·쪽지 부착, 새로고침 유지, 데스크톱·모바일 화면 확인.
- 부착 개수 제한, 다른 집 접근 거절, 오래된 revision 거절, 동시 요청 중 한 건만 반영은 서버 테스트로 확인.

## 회원 인증 (feature/postgres-auth)

- 서버 테스트 10개, Node 테스트 5개 통과. 실제 PostgreSQL 17에 Flyway V1 적용.
- 브라우저에서 빈 입력 오류 문구, 가입, 틀린 비밀번호, 로그인, 새로고침 세션, 로그아웃 확인.
- DB에 BCrypt 해시·이메일 암호문·HMAC만 저장됨을 테스트 계정으로 확인. PostgreSQL 재시작 후 로그인 유지(데이터 영속성) 확인.

## 커플 초대 (2026-11-10)

- Java 테스트 17개 성공. 집 없는 수락, 기존 집 삭제 동의, 제3자 차단, 코드 만료·재발급·취소, 같은 코드 동시 수락, DB 오류 시 롤백.
- 별도 PostgreSQL에서 V2 → V3 마이그레이션 후 가구 9개·revision 전부 일치.
- 실제 Chrome 두 계정으로 초대 발급·수락, 두 사람 프로필, 각자 편집, 앱 재시작 후 복원 확인.

## 하트·방명록·관리자 (2026-11-10)

- Java 테스트 21개 성공. 관리자 API 차단, 권한 회수 즉시 반영, 하트 중복·동시 요청 단일 반영, 자기 집 투표 차단, 콘셉트 변경 시 집계 초기화.
- 실제 Chrome으로 관리자 콘셉트 공개, 로그인 후 방문 복귀, 하트 토글, HTML이 섞인 방명록의 글자 표시, 앱 재시작 후 보존 확인.

## 검증하지 못한 것

- 두 번째 기기의 같은 와이파이(LAN) 접속.
- 실제 네트워크가 끊기는 시점별 브라우저 E2E.
