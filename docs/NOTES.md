# 냉장고 쪽지

수정하기에서 냉장고와 쪽지를 놓고 쪽지 그림, 연필 버튼 또는 가구 상자 아래 쪽지 목록을 누릅니다. 200자 이내로 내용을 작성하고 **방문객에게 공개하기**를 선택한 뒤 저장합니다. 취소하면 내용과 공개 설정은 바뀌지 않습니다.

새 쪽지와 기존 내용 없는 쪽지는 기본적으로 비공개입니다. 비공개 쪽지는 집 멤버 두 명만 읽고 수정할 수 있습니다. 방문객에게는 빈 쪽지 그림만 보이며 본문·미리보기 API도 내용을 반환하지 않습니다. 관리자는 관리자라는 이유만으로 다른 집의 비공개 쪽지를 읽을 수 없습니다.

공개 쪽지는 집 보기의 쪽지 그림/목록에서 펼쳐 읽습니다. 목록에는 첫 줄 최대 40자를 표시합니다. HTML은 실행하지 않고 문자로 표시합니다. 공개를 해제하면 이후 조회는 차단됩니다. 이미 공개됐을 때 읽은 내용까지 회수하는 기능은 아닙니다.

V5__note_contents.sql이 note_contents를 추가합니다. furniture_id가 배치된 쪽지 UUID를 참조하고 body, is_public, revision, updated_at을 저장합니다. 내용이 아직 없는 쪽지는 빈 내용·비공개·revision 0으로 취급합니다. 별도 이미지나 S3는 필요하지 않습니다.

가구 저장은 기존 배치 행을 갱신하고 실제 삭제 대상만 지웁니다. 따라서 냉장고 이동·회전, 다른 가구 추가 중에도 쪽지 내용이 유지됩니다. 쪽지를 지우거나 냉장고 연쇄 삭제를 확인하면 해당 내용도 삭제합니다.

공동 편집 중에는 쪽지를 연 사람이 냉장고 묶음을 잠급니다. 저장할 때 쪽지 revision을 비교하므로 끊긴 연결/오래된 창에서 다시 저장해도 다른 사람의 최신 내용을 조용히 덮어쓰지 않습니다.
