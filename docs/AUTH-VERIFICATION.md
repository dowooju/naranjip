# 회원 인증 검증 기록

- 브랜치: feature/postgres-auth
- 서버 테스트: 10개 통과 (회원가입/로그인/중복/빈 입력/CSRF/암호화 저장/가구 소유권 및 배치)
- Node 테스트: 5개 통과 (입력 검증 2개, 기존 배치 3개)
- 실제 PostgreSQL 17: Flyway V1 정상 적용
- 브라우저: 빈 아이디/비밀번호 빨간 문구, 회원가입 필수 이메일, 가입, 틀린 비밀번호, 올바른 로그인, 새로고침 세션, 로그아웃 확인
- 인증된 꾸미기 화면: CSRF를 포함한 가구 추가/삭제 확인
- 데스크톱 및 모바일 오류 표시 스크린샷 확인
- DB에는 BCrypt 해시, v1 이메일 암호문, HMAC 중복 확인값만 저장됨을 테스트 계정으로 확인
- PostgreSQL Pod 재시작 후 동일 테스트 계정 로그인 성공: PVC 영속성 확인

개인 회원정보/DB 비밀번호/암호화 키는 이 문서에 기록하지 않았습니다.
