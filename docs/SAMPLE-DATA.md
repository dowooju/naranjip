# 샘플 집과 계정

나란집 앱은 처음 켜질 때 구경용 샘플 집 4채를 자동으로 만듭니다. 이미 있으면 다시 만들지 않으므로 앱이나 DB Pod를 재시작해도 중복되지 않습니다. PVC가 유지되는 한 계속 남습니다.

| 기획 | 아이디(거주자 이름) | 집 | 일반 하트 | 방명록 |
| --- | --- | --- | --- | --- |
| S1 / H1 | 햇살방 | 문·러그·식탁·의자 2·냉장고(쪽지 공개 1, 비공개 1)·소파·큰 화분 | 3 (S2·S3·S4) → 1위 | S2가 작성 |
| S2 / H2 | 구름집 | 작은 화분·책상(액자 1)·의자·세운 소파·러그·왼쪽 벽 문 | 2 (S1·S3) → 2위 | S3가 작성 |
| S3 / H3 | 달빛집 | 화분 2·냉장고(공개 쪽지)·러그·소파·의자·책상 | 1 (S1) → 공동 3위 | S4가 작성 |
| S4 / H4 | 솔바람집 | 문·식탁·의자 2·화분 2 | 1 (S2) → 공동 3위 | S1이 작성 |

- **이번 주 콘셉트**: 관리자가 아직 콘셉트를 등록하지 않은 상태라면 "비 오는 날의 집"을 열고, 달빛집에 콘셉트 하트 3개(S1·S2·S4)를 넣어 일반 순위와 다른 1위를 만듭니다. 이미 콘셉트가 진행 중이면 그 콘셉트는 건드리지 않습니다.
- 샘플 계정은 관리자가 아닙니다. 이메일은 `s1@sample.naranjip.local` 형식입니다.
- 가구는 실제 배치 규칙(경계·겹침·벽·부착)을 그대로 거쳐 놓습니다.

## 샘플 계정으로 로그인하려면

비밀번호는 **처음 만들어질 때 한 번만** 정해집니다. `SAMPLE_PASSWORD`가 없으면 아무도 모르는 무작위 비밀번호가 되어 구경 전용 계정이 됩니다. 로그인도 하고 싶다면 이 버전을 처음 배포하기 **전에** Secret에 넣어 두세요. 실제로 쓰는 비밀번호는 재사용하지 마세요.

```powershell
kubectl --context rancher-desktop -n room-demo patch secret naranjip-auth --type merge -p '{\"stringData\":{\"SAMPLE_PASSWORD\":\"시연용-비밀번호-8자이상\"}}'
```

이미 무작위 비밀번호로 만들어졌다면, 네 계정을 지운 뒤 앱을 재시작해야 새 비밀번호로 다시 만들어집니다.

## 끄기

`SAMPLE_DATA=false` 환경변수를 주면 샘플을 만들지 않습니다. 이미 만들어진 데이터는 지우지 않습니다. 테스트 환경은 기본으로 꺼져 있고, `SampleDataTest`만 별도 DB에서 켜서 검증합니다.

구현: `src/main/java/com/naranjip/infrastructure/SampleDataSeeder.java`
