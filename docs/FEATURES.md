# 기능 안내

## 1. 꾸미기

1. 회원가입 → **새 집 만들기**(또는 초대 코드 입력) → 우리집 → **수정하기**.
2. 오른쪽 가구를 방으로 드래그합니다. 클릭하면 빈자리에 자동으로 놓입니다.
3. 파란 칸은 놓을 수 있는 자리, 회색 칸은 놓을 수 없는 자리입니다. 놓는 즉시 서버에 저장됩니다.
4. 가구를 클릭하면 ↻ 회전, ⌫ 삭제. Esc는 선택 취소입니다.

| 가구 | 크기 / 규칙 |
| --- | --- |
| 의자, 작은 화분, 큰 화분, 냉장고 | 1×1 (냉장고에는 쪽지 최대 3개) |
| 책상 | 2×1, 액자 최대 2개 |
| 소파 | 2×1 |
| 식탁 | 2×2 |
| 러그 | 3×2, 다른 가구 아래에 깔 수 있음(러그끼리는 겹침 금지) |
| 문 | 왼쪽/오른쪽 벽에만, 방향은 벽에 따라 자동 |
| 액자 / 쪽지 | 책상 / 냉장고에만 붙음. 부모 가구를 따라 움직이고, 부모를 지우면 함께 지워짐(확인창) |

- 한 집에 최대 150개. 방 밖이나 겹치는 자리에 놓으면 저장하지 않고 원래 자리로 돌아갑니다.
- 가구 그림은 `src/main/resources/static/furniture-atlas.png` 한 장(4열×3행, 11종)에서 잘라 그립니다. 회전은 좌우 반전으로 표현합니다.
- 커플 두 사람이 동시에 수정하면 실시간으로 반영됩니다 → [실시간 공동 편집](REALTIME-EDITING.md).

## 2. 커플 초대

- 혼자 사는 집에서 **7자리 초대 코드**(24시간, 1회용)를 발급합니다. 다시 발급하면 이전 코드는 무효입니다.
- 받은 사람이 코드를 입력하면 상대 이름과 "기존 방 삭제" 여부를 먼저 보여 줍니다. 확인해야만 수락됩니다.
- 수락하면 받은 사람의 이전 집은 지워지고 두 사람이 같은 집의 멤버가 됩니다(한 집 최대 2명).
- 이후 두 사람 모두 같은 집을 보고 편집할 수 있습니다. 연결 해제 기능은 없습니다.

## 3. 냉장고 쪽지

- 냉장고에 붙인 쪽지를 누르면 200자까지 쓸 수 있고, **방문객에게 공개하기**를 고를 수 있습니다.
- 기본은 비공개입니다. 비공개 쪽지는 집 멤버 두 명만 읽을 수 있고, 관리자도 읽을 수 없습니다.
- 방문객은 공개 쪽지만 읽습니다. 내용은 HTML로 해석하지 않고 글자로만 보여 줍니다.

## 4. 하트·방명록·이번 주 콘셉트

- 로그인하면 집마다 **일반 하트** 1개, 이번 주 **콘셉트 하트** 1개를 줄 수 있습니다. 다시 누르면 취소됩니다. 자기 집에는 줄 수 없습니다.
- 방명록은 1~200자, 최신순 20개씩. 작성자나 그 집 멤버가 지울 수 있습니다.
- 꾸민 집만 순위에 오릅니다(최대 50집, 동점은 공동 순위). 로그인 없이도 집과 방명록을 구경할 수 있습니다.

### 관리자와 콘셉트 등록

기본 관리자 계정은 없습니다. 사이트에서 가입한 계정(예: `sudo1234`)에 DB에서 권한을 줍니다.

```bash
docker compose exec postgres psql -U naranjip -d naranjip -c "UPDATE accounts SET is_admin=TRUE WHERE login_id='sudo1234';"
```

`UPDATE 1`이면 성공, `UPDATE 0`이면 그 아이디의 계정이 없습니다(아이디는 소문자로 저장). 회수는 `TRUE`를 `FALSE`로 바꿉니다. 권한은 요청마다 DB에서 확인하므로 바로 반영됩니다.

관리자로 로그인 → 홈의 **이번 주 콘셉트 관리**(`/#admin`) → 제목(80자)과 안내문(1,000자) 입력 → **공개하기**. 즉시 바뀌며, 새 콘셉트의 하트는 0부터 다시 셉니다. 이전 기록과 일반 하트·방명록은 남습니다.

## 5. 샘플 집

앱이 처음 켜질 때 구경용 샘플 집 4채를 한 번만 만듭니다(`infrastructure/SampleDataSeeder.java`). 이미 있으면 다시 만들지 않습니다.

| 아이디(거주자) | 일반 하트 | 비고 |
| --- | --- | --- |
| 햇살방 | 3 → 1위 | 냉장고 쪽지 공개 1·비공개 1 |
| 구름집 | 2 → 2위 | 책상에 액자 |
| 달빛집 | 1 → 공동 3위 | 콘셉트 하트 3개 → 콘셉트 1위 |
| 솔바람집 | 1 → 공동 3위 | |

- 콘셉트가 아직 없으면 "비 오는 날의 집"을 엽니다. 이미 있으면 건드리지 않습니다.
- 샘플 계정은 기본적으로 **구경 전용**(아무도 모르는 무작위 비밀번호)입니다. 로그인해 보려면 `.env`에 `SAMPLE_PASSWORD=8자이상비밀번호`를 넣고 `docker compose up -d`를 실행합니다. 앱이 켜질 때마다 샘플 계정 4개의 비밀번호만 그 값으로 맞춥니다. 공개 서버에서는 누구나 로그인할 수 있게 되니 시연할 때만 쓰세요.
- 샘플을 만들지 않으려면 `.env`에 `SAMPLE_DATA=false`.
